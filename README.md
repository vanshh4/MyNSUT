# MyNSUT

> A modern, student-first platform built to simplify campus life at Netaji Subhas University of Technology (NSUT).

> **🚧 Status:** Work in Progress (Early Development)

---

## Overview

MyNSUT is an open-source web platform designed to provide NSUT students with a centralized, intuitive, and modern experience for accessing campus-related information and services.

The project aims to eliminate the need for students to navigate multiple websites, portals, and communication channels by bringing relevant information together in one place.

This project is being developed independently and is **not affiliated with or endorsed by NSUT**.

---

## Vision

To build a platform that becomes the go-to digital companion for every NSUT student by providing fast, reliable, and easy access to essential campus resources.

Our long-term goal is to create a scalable platform that can continuously evolve based on student needs while maintaining a clean, responsive, and accessible user experience.

---

## Current Development Status

The project is currently under active development.

At this stage, the primary focus is on:

- Setting up the project architecture
- User authentication
- Backend infrastructure
- Database design
- UI/UX foundations
- Responsive frontend

Features will be introduced incrementally as development progresses.
